# Reports

> **Status:** current  
> **Updated:** 2026-08-16  
> **Owner:** maintainers

Generated audit reports and one-off investigation notes live here.

Maintenance scripts under `scripts/` (and any `scripts/maintenance/` helpers) may write default reports into this folder. Report **files** are gitignored; this README stays tracked so the folder purpose is clear.

These files are useful while tuning GUID comments, localization coverage, and whitelist behavior. They are **not** runtime inputs for the app.
